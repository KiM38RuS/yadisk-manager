# ☁️ YaDisk Manager

[![Version](https://img.shields.io/badge/version-0.11.6-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()
[![Windows](https://img.shields.io/badge/platform-Windows%2010%2F11-orange)]()

**YaDisk Manager** — бесплатный on-demand клиент Яндекс.Диска для Windows. Альтернатива официальному приложению после введения платной подписки Яндекс 360.

> ⚠️ **Дисклеймер:** Этот проект не связан с компанией Яндекс, не одобрен ей и не аффилирован с ней. Используется официальный публичный REST API Яндекс.Диска в соответствии с [условиями использования](https://yandex.ru/legal/disk_api/ru/).

## 🔍 Как это работает

```
☁️ Облако          Локально (кеш)
┌──────────┐      ┌──────────┐
│ photo.jpg│ ───→ │☁️ облако │ ← видно, весит 0 байт
│ doc.docx │      │☁️ облако │
│  data.xls│      │💾 скачан │ ← 10 МБ
└──────────┘      └──────────┘
                      │
                 двойной клик
                      │
                      ▼
              ☁️ → 💾 скачивается
                      │
                 редактируешь
                      │
                      ▼
              ✏️ → авто-загрузка
```

- Файлы **видны** в проводнике программы сразу (метаданные из облака)
- Скачиваются **только по требованию** — двойной клик или команда «Скачать»
- Изменённые файлы **автоматически загружаются** обратно в облако
- Фоновый опрос изменений каждые 60 секунд

## 🎮 Возможности

| Функция | Как |
|---|---|
| **Просмотр файлов** | Дерево папок слева, таблица файлов справа |
| **Мгновенная навигация** | Все файлы в БД при старте → клик по папке без задержки |

| **Удаление** | Кнопка 🗑 или Delete |
| **Новая папка** | Кнопка 📂 |
| **Публичная ссылка** | Кнопка 🔗 |
| **Прогресс** | Реальный % при скачивании/загрузке |
| **Конфликты** | Диалог: локальный / облачный / отмена |
| **Системный трей** | Иконка в лотке |
| **Автозапуск** | Настройка (реестр Windows) |

| **Сохранение положения окна** | Настройка (геометрия запоминается) |

## 📋 Системные требования

- **Windows** 10 или 11
- **Интернет** для связи с API Яндекс.Диска

На данный момент требуется **Python 3.10+**. В будущем будет доступна сборка `.exe` без необходимости устанавливать Python.

## 🚀 Запуск

```cmd
git clone https://github.com/your-username/yadisk-manager.git
cd yadisk-manager
pip install -r requirements.txt
python main.py
```

> В будущем — скачать `.exe` из [релизов](../../releases) и запустить.

### Первый запуск

1. Программа покажет диалог с инструкцией
2. Перейдите на [oauth.yandex.ru](https://oauth.yandex.ru/)
3. Создайте приложение:
   - Название: любое (например «MyDisk»)
   - Платформа: **Веб-сервисы**
   - Redirect URI: `https://oauth.yandex.ru/verification`
   - Права: **Яндекс.Диск** → все галочки
4. Нажмите **«Получить токен»**
5. Скопируйте токен и вставьте в программу
6. Токен сохранится — при следующих запусках авторизация не нужна

## 📂 Где что хранится

| Что | Путь |
|---|---|
| **Кеш скачанных файлов** | `%USERPROFILE%\.yadisk-cache\` |
| **База данных (SQLite)** | `%APPDATA%\yadisk-client\yadisk.db` |
| **Конфиг (токен, настройки)** | `%APPDATA%\yadisk-client\config.json` |

## 🐛 Известные ограничения

- Только для Windows (автозапуск через реестр)
- Бесплатный тариф Яндекс.Диска — **5 ГБ**
- API-лимит: 40 запросов в секунду
- Нет шифрования на клиенте (файлы передаются по HTTPS)
- Нет webhook'ов — Яндекс.Диск REST API не поддерживает push-уведомления
