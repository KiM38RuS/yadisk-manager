⚠ **Исправлено (v3 — полный фикс):**
- (а) `_DebouncedHandler._flush()` — детектор пар delete+create в одной директории: если файл исчез и появился другой в той же папке — это `moved`.
- (б) `_handle_local_modified` больше не падает в `_handle_local_created` для неизвестных файлов — исправлены ложные перезагрузки.
- (в) `_handle_local_moved` → `_MoveCloudThread` → `api.move()` синхронизирует с облаком.
- (г) **`_ReconcileLocalCacheThread`** — сверка БД vs диск при старте: каждый скачанный/изменённый файл проверяется на существование. 1 пропал + 1 появился → rename, иначе → delete.
- (д) **Запуск reconcile перенесён в `_initial_load`** (2s таймаут), а не в `_on_all_files_loaded` — раньше reconcile ждал полной выгрузки всех файлов из облака (AllFilesThread с resume offset=68000 мог идти минуты). Теперь сверка запускается через 2с после старта, независимо от облака.
