  - **Изменено**: в статус-баре перед надписью «Закрытие программы...»/«Перезагрузка программы...» показывается волновой спиннер Брайля

## v0.11.5 (2026-08-01)

- **Исправлено (критическое)**: фризы UI при старте/навигации — SQLite-запросы вынесены из главного потока. На БД со 100К+ файлов (`get_children`, `sync_children_from_api` и др.) UI зависал на 0.5–1.5с при старте и каждом открытии папки (FREEZE-дампы в логе). Реализация:
  - **Новый** `FolderLoadThread` (ui_threads.py) — выполняет в фоне весь конвейер: API-запрос списка папки → `sync_children_from_api` (с fallback на upsert) → `get_children` → nav-fix (проверка cloud_only файлов на диске + md5) → повторное чтение → сборка items → lazy reverse-проверка
  - `_apply_file_list` удалена; `_load_folder_async`/`_load_folder_local`/`_navigate_to_folder` — теперь запускают `_start_folder_load()` → `_on_folder_loaded()` применяет к UI только быстрые операции (модель таблицы, pend_upload, дерево, очередь reverse-фетча)
  - Защита от race: `_on_folder_loaded` игнорирует результат для папки, от которой пользователь уже ушёл (`path != _current_path`)
  - Восстановление выделения при навигации — через `_pending_selection` (асинхронно, после применения данных)
  - Перерисовка таблицы пропускается, если набор путей не изменился (нет мигания)
- **Проверено**: старт менеджера на БД 95K+ файлов — **0 FREEZE** (раньше 6 фризов по 0.5–1.5с); быстрый прогон pytest 100/100

## v0.11.3 (2026-08-01)

- **Добавлено**: Обратная синхронизация (облако → локальный кеш) — 3-слойный гибридный механизм:
  - **Слой 1 (poll)**: `_on_poll_result()` теперь проверяет не только новые файлы, но и существующие скачанные — при изменении MD5 в облаке авто-скачивание через MetaFetch
  - **Слой 2 (bulk)**: Периодический `_AllFilesThread` каждые 15 минут (первый через 10с после старта). После загрузки — `get_changed_downloaded_files()` сравнивает `md5` с `last_sync_md5`, изменённые файлы авто-скачиваются
  - **Слой 3 (lazy nav)**: При навигации по папке проверяет каждый `downloaded` файл на расхождение MD5 и при необходимости синхронизирует
- **Добавлено**: `db.get_changed_downloaded_files()` — SQL-запрос для поиска downloaded файлов с изменённым облачным MD5

- **Добавлено**: `tests/test_reverse_sync_scenarios.py` — 6 сценариев обратной синхронизации (5–10):

  - Конфликт (облако и локально изменились) ✅
